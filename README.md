# ATC Radar System

A full-stack Air Traffic Control (ATC) radar application built with Spring Boot and HTML5 Canvas.

## Tech Stack
* **Backend:** Java 17, Spring Boot 3.2.0, REST APIs
* **Database:** PostgreSQL
* **Frontend:** HTML5 Canvas, JavaScript, CSS3

## Features
* Real-time flight vector tracking and radar visualizer via HTML5 Canvas.
* Flight data management and telemetry tracking.
* RESTful backend endpoints for airspace monitor updates.
